# Can AI Understand a Tile-Based Game World?
## UCSC Augmented Design Lab — draft presentation outline

1. **Question and invitation** — Can AI understand how tiles form meaningful game structures? An exploratory, low-pressure project.
2. **Previous work** — WFC-to-SAT experiments, Zelda and Tiny Town structures; `sat-tilegen` is paper-oriented research code.
3. **What's missing?** — Local tile adjacency does not by itself guarantee preservation of higher-level structures.
4. **Objects, shapes, textures** — Zelda multi-tile structure; pool-like bounded shape; grass or terrain texture. Use existing screenshots where possible.
5. **What would we benchmark?** — Recognition, grouping, relationships, allowed changes, and valid tile use; fixed examples and repeatable scoring.
6. **Small experiments and possible applications** — Annotate examples, test models, compare baselines. Optional future visual preprocessor: highlight suggested regions, allow confirmation, feed constraints to SAT generation.
7. **Invitation to join** — Read, discuss, label, test, or code as interest allows; no large upfront commitment.
8. **References and links** — GameTileNet; Tile Embedding; VGLC; Patterns and Procedural Content Generation; Game Level Blending Using a Learned Level Representation; project and related code repositories.

Target: approximately 8–10 minutes, with time for questions. References are suggested reading, not claims of completed reviews.
