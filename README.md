# Tile Understanding Benchmark

An exploratory project associated with the UCSC Augmented Design Lab.

## Question
How well can multimodal AI systems understand and use tiles in 2D game levels—not only recognizing individual tiles, but identifying objects, shapes, textures, and the relationships among them?

## Initial goals
- Assemble a small, versioned set of tile-map examples and reference answers.
- Test current vision-language models on recognition, grouping, reasoning, and editing tasks.
- Compare results with simple algorithmic baselines.
- Re-run the same benchmark periodically to observe progress.

## Ways to contribute
Suggest an example, annotate a region, test a model, discuss a paper, or implement a small baseline. Participation is exploratory and contributions can be self-contained.

## Possible future application
A preprocessor that suggests object, shape, and texture regions for a tile-based generator, with optional user confirmation and eventual translation into structural constraints. This is a research direction, not a required initial deliverable.
