# Tiny Town pilot — Day 1
30 numbered image crops for a preliminary tile understanding benchmark. Source: Tiny Town image embedded on slide 4 of tile-understanding-student-papers-FIXED.pptx, attributed to Kenney Tiny Town (CC0), https://kenney.nl/assets/tiny-town. This is a presentation-derived raster, not a verified original 16x16 asset atlas. Crop boundaries are estimated from the visible grid; blue backgrounds/grid edges may remain. Do not treat these crops as pixel-exact original assets. IDs T01–T30 are fixed for this pilot. The manifest records crop coordinates; labels are deliberately deferred to Day 2. Selection is purposive, not random or exhaustive. Before a formal benchmark, verify against the original asset pack and check whether the selected crops represent distinct tiles. No model tests or GitHub push have been performed.

Files: numbered_tiles.png (model input), source_atlas.png (provenance), tiles/ (individual crops), tile_manifest.csv (ID mapping). Do not provide the answer key to models in later experiments.
